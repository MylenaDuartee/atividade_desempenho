# Referências Java

Esta pasta contém exemplos de teste funcional (Selenium/JUnit) e desempenho (Gatling) para o catálogo.

Os arquivos-fonte foram preservados do material original, mas este pacote não contém um `pom.xml`. Portanto, os comandos Maven descritos no roteiro original ainda não podem ser executados diretamente nesta pasta.

Para apontar os exemplos à aplicação local, inicie o servidor do desafio em outro terminal:

```bash
cd ../../desafio
python app.py
```
